Envoyer les journaux d'un appareil vers BL-FMO

Dans les réglages de l'appareil, cherchez « Syslog », « Remote log » ou « Journal distant » et indiquez : serveur , port 514, protocole UDP.

MikroTik RouterOS

Repérer l'action d'envoi existante, puis la diriger vers BL-FMO :

/system logging action print where target=remote
/system logging action set [find target=remote] remote= remote-port=514

Ubiquiti airOS

Onglet Services, section System Log : cocher Remote Log, adresse , port 514.

Le nom affiché vient de la chaîne de diffusion : un appareil dont l'adresse IP figure dans la page Chaîne prend son nom. Sinon, BL-FMO affiche le nom d'hôte envoyé par l'appareil ou son adresse.
